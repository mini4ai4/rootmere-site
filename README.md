# rootmere.com — собранный сайт

Здесь лежит **результат сборки**, а не исходники. Исходники (шаблоны `body_*.html`,
`head.html`, `build_site.py`) — в рабочей папке `~/agents/chief/paperroots`.

Репозиторий нужен для выкладки: хостинг забирает содержимое этой ветки как есть.

## Как обновить сайт
```
cd ~/agents/chief/paperroots
python3 build_site.py          # пересобрать
python3 publish_site.py        # скопировать в репозиторий и запушить
```

## Схема адресов
Страницы лежат папками: `faq/index.html` отдаётся по адресу `/faq/`.
Так адрес не зависит от хостинга — работает одинаково и на Netlify, и на Cloudflare,
и на Render. Файл `_redirects` держит постоянные переадресации со старых адресов с `.html`.
